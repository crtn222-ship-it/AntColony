# 🐜 مستعمرة النمل — مشروع أندرويد (تطبيق حقيقي أوفلاين، بلا روابط)

تطبيق أندرويد أصلي: لعبة مستعمرة النمل كاملة داخل التطبيق — تعمل أوفلاين.

## ✅ لا خطوات إضافية
اللعبة مضمّنة داخل المشروع وتعمل أوفلاين — ابنِ الـ APK مباشرة.
> ملاحظة: نسخة الويب على Perchance ما زالت تعمل كالمعتاد — هذا المشروع نسخة أوفلاين مستقلة.

## البناء (Android Studio)
1. فك الضغط وافتح مجلد `AntColony` في Android Studio (الإصدار Koala أو أحدث).
2. انتظر مزامنة Gradle (يحتاج إنترنت أول مرة).
3. شغّل على جهاز/محاكي بزر ▶️، أو ابنِ APK من:
   **Build ← Build Bundle(s) / APK(s) ← Build APK(s)**
   ستجد الملف في `app/build/outputs/apk/debug/app-debug.apk`.

## البناء من سطر الأوامر
```sh
cd AntColony
./gradlew assembleDebug        # لينكس/ماك
gradlew.bat assembleDebug      # ويندوز
```
