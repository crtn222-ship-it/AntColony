# مجسمات glb — كيف تضيف موديلاتك الخاصة

ضع ملفاتك هنا بهذه الأسماء بالضبط:

| الملف | يظهر كـ |
|---|---|
| `src/models/ant.glb` | النملة (اللاعب والعمال) |
| `src/models/soldier.glb` | الجندي |
| `src/models/beetle.glb` | الخنفساء العدو |

قواعد بسيطة حتى يظهر المجسم صح:

1. **الاتجاه:** الأمام = المحور `+Z` (مثل مجسمات three.js الجاهز).
2. **الأرضي:** الأقدام قريب من `y = 0` (الكود يضبطها تلقائياً حتى لو لم تكن).
3. **الحجم:** أي حجم — الكود يوحّد تلقائياً (النملة ≈ 2.4 وحدة، الملكة ≈ 3.4).
4. **المواد:** `MeshStandardMaterial` يفضل (إضاء اللعب مضبوط عليه).
5. **الحركة:** المجسم الخارجي يحصل على تمايل بسيط تلقائياً. الأرجل الإجرائي المتحرك يعمل فقط
   مع البديل الداخلي (بدون ملف) — لو تريد أرجل متحركة مع مجسمك، اترك ملف `ant.glb` فارغاً
   (احذفه) وسيعمل الإجرائي.

غياب أي ملف = اللعب يستخدم المجسم الإجرائي تلقائياً، بدون أي خطأ.
الملكة مرسومة داخل لعبة (تعيش في غرفتها داخل العش فقط ولا تخرج للسطح أبداً)
ولا تحتاج أي مجسم خارجي.

تلميح: صدّر من Blender عبر File → Export → glTF 2.0 (`.glb`) مع Applied Transforms.
